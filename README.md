# 🧠 Task Management API (Backend)

This is the backend API for the TickTick-inspired Task Management App. It supports task creation, updates, recurrence rules, and integrates with a PostgreSQL database.

## 📦 Tech Stack

- **Node.js** with **Express** or **Nest.js**
- **PostgreSQL** (via Prisma / Sequelize / Knex)
- **REST API** with CRUD operations
- **CORS + Middleware**
- **Dotenv for environment config**
